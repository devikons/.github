# Devikons

Custom software from scratch or taken over. Business software you subscribe to.

## What we do

- **Custom software:** web applications, SaaS products, APIs and integrations, built from scratch or taken over from another developer.
- **Business software by subscription:** systems for day-to-day operations, run by us.
- **After launch:** we stay and keep the system running.

## Who we work with

Startups and businesses worldwide.

## How an engagement runs

1. We start with your problem and agree a small first version.
2. We deliver in small steps you can check.
3. We tell you early if something looks like a bad idea.

When we take over an existing app, we read it first, fix what is broken and add features without breaking what works.

## Technologies

Laravel, PHP, Vue.js, React, Livewire, Inertia, Tailwind CSS, MySQL, Stripe, PayPal, GitHub Actions.
